## Подробное описание дефектов

### BR-01 — Неверная цена на публичной странице

**Приоритет:** P1 — высокий  
**Экран:** Карточка товара

#### Предусловия

Открыто объявление № 52291995943.

#### Шаги воспроизведения

1. В форме редактирования установить цену `25 000 руб.`.
2. Сохранить объявление.
3. Открыть публичную страницу объявления.
4. Проверить цену в правой верхней части страницы.

#### Фактический результат

На публичной странице отображается цена **52 000 ₽**.

#### Ожидаемый результат

На публичной странице должна отображаться сохранённая в форме цена **25 000 ₽**.

#### Обоснование приоритета

Цена является одним из основных параметров объявления. Ошибка напрямую влияет на решение покупателя и может привести к отказу от покупки.

### BR-02 — Неверное количество товара на публичной странице

**Приоритет:** P1 — высокий  
**Экран:** Карточка товара

#### Предусловия

В форме редактирования в поле «Количество» сохранено значение `1 шт.`.

#### Шаги воспроизведения

1. Сохранить объявление с количеством `1 шт.`.
2. Открыть публичную страницу объявления.
3. Проверить статус наличия рядом с ценой.

#### Фактический результат

Отображается статус **«В наличии 3 шт.»**.

#### Ожидаемый результат

Должно отображаться количество **1 шт.**

#### Обоснование приоритета

Покупатель получает неверную информацию о доступном остатке товара. Это может привести к оформлению или обсуждению покупки несуществующих единиц товара.

### BR-03 — Доставка ошибочно отображается как отключённая

**Приоритет:** P1 — высокий  
**Экран:** Карточка товара

#### Предусловия

В форме редактирования параметр «Авито Доставка» установлен в значение **«Включена»**.

#### Шаги воспроизведения

1. Включить Авито Доставку.
2. Сохранить объявление.
3. Открыть публичную страницу объявления.
4. Проверить блок доставки.

#### Фактический результат

На публичной странице отображаются сообщения:

- **«Доставка недоступна»**;
- **«Продавец отключил доставку для объявления»**.

#### Ожидаемый результат

Доставка должна отображаться как доступная. Покупателю должны быть доступны настроенные способы доставки.

#### Дополнительная информация

В карточке продавца доставка отображается включённой, что дополнительно подтверждает рассинхронизацию между представлениями объявления.

#### Обоснование приоритета

Ошибка блокирует для покупателя важный способ получения товара и может приводить к потере заказов.

---

### BR-04 — Искажены сведения о состоянии товара

**Приоритет:** P1 — высокий  
**Экран:** Карточка товара

#### Предусловия

В форме редактирования сохранены следующие значения:

| Параметр | Ожидаемое значение |
|---|---|
| Общее состояние | Отличное |
| Состояние обивки | Всё в порядке |
| Сиденье и спальное место | Ровное |
| Раскладной механизм | Всё в порядке |
| Каркас | Всё в порядке |
| Подушки для спинки | В комплекте |
| Химчистка | Не нужна |

#### Шаги воспроизведения

1. Сохранить указанные значения в форме редактирования.
2. Открыть публичную страницу объявления.
3. Перейти к блоку «О диване».
4. Сравнить отображаемые значения с сохранёнными.

#### Фактический результат

Часть параметров отображается неверно:

| Параметр | Фактическое значение | Ожидаемое значение |
|---|---|---|
| Состояние обивки | Требует замены | Всё в порядке |
| Раскладной механизм | Требуется ремонт | Всё в порядке |
| Каркас | Требуется ремонт | Всё в порядке |

Остальные значения блока отображаются корректно.

#### Ожидаемый результат

Все сведения о состоянии должны совпадать со значениями, сохранёнными в форме редактирования.

#### Обоснование приоритета

Публичная страница ошибочно сообщает о серьёзных дефектах товара. Это существенно снижает привлекательность объявления и может привести к отказу покупателя.

### BR-05 — Искажены ключевые характеристики дивана

**Приоритет:** P1 — высокий  
**Экран:** Карточка товара

#### Предусловия

В форме редактирования сохранены следующие параметры:

- форма — `Угловой`;
- модульный — `Да`;
- спальное место — `Есть`;
- раскладной механизм — `Есть`.

#### Шаги воспроизведения

1. Сохранить объявление с указанными характеристиками.
2. Открыть публичную страницу.
3. Перейти к блоку «Характеристики».
4. Сравнить значения с формой редактирования.

#### Фактический результат

На публичной странице отображаются противоположные значения:

| Параметр | Фактическое значение | Ожидаемое значение |
|---|---|---|
| Форма | Прямой | Угловой |
| Модульный | Нет | Да |
| Спальное место | Нет | Есть |
| Раскладной механизм | Нет | Есть |

При этом на той же странице указан тип механизма `Еврокнижка` и размер спального места `140 × 200 см`, что противоречит значениям «Раскладной механизм: Нет» и «Спальное место: Нет».

#### Ожидаемый результат

Публичная страница должна отображать сохранённые характеристики:

- форма — `Угловой`;
- модульный — `Да`;
- спальное место — `Есть`;
- раскладной механизм — `Есть`.

#### Обоснование приоритета

Ошибочно изменены основные потребительские характеристики товара. Покупатель может исключить объявление из поиска или отказаться от товара из-за недостоверных данных.

### BR-06 — Неверный адрес на публичной странице

**Приоритет:** P1 — высокий  
**Экран:** Карточка товара

#### Предусловия

В форме редактирования сохранён адрес: `Москва, пл. Революции, 3`.

#### Шаги воспроизведения

1. Сохранить адрес `Москва, пл. Революции, 3`.
2. Открыть публичную страницу объявления.
3. Проверить блок «Местоположение».

#### Фактический результат

На публичной странице отображается адрес **«Москва, пл. Революции, 5»**.

#### Ожидаемый результат

Должен отображаться сохранённый адрес **«Москва, пл. Революции, 3»**.

#### Дополнительная информация

На странице владельца (`Карточка продавца`) адрес отображается корректно: `Москва, пл. Революции, 3`.

#### Обоснование приоритета

Неверный номер дома может привести покупателя по неправильному адресу и сорвать встречу с продавцом.

### BR-07 — Перепутаны глубина и высота товара

**Приоритет:** P2 — средний  
**Экран:** Карточка товара

#### Предусловия

В форме редактирования указаны размеры:

- ширина — `220 см`;
- глубина — `95 см`;
- высота — `85 см`.

#### Шаги воспроизведения

1. Сохранить указанные размеры.
2. Открыть публичную страницу объявления.
3. Перейти к блоку «Характеристики».
4. Проверить глубину и высоту.

#### Фактический результат

На публичной странице указано:

- глубина — `85 см`;
- высота — `95 см`.

Значения глубины и высоты поменяны местами.

#### Ожидаемый результат

Должны отображаться значения:

- глубина — `95 см`;
- высота — `85 см`.

#### Дополнительная информация

В карточке продавца размеры отображаются правильно.

#### Обоснование приоритета

Ошибка может помешать покупателю правильно оценить габариты товара, однако не блокирует просмотр объявления или связь с продавцом.

### BR-08 — Неверный заголовок на странице владельца

**Приоритет:** P2 — средний  
**Экран:** Карточка продавца

#### Предусловия

В форме редактирования в поле «Название» сохранено:

`Диван угловой модульный QA Sofa 2026 раскладной`

#### Шаги воспроизведения

1. Сохранить объявление с указанным названием.
2. Открыть страницу объявления владельца.
3. Проверить заголовок в верхней части страницы.

#### Фактический результат

Отображается заголовок:

`Диван прямой QA Sofa 2026 раскладной`

В заголовке:

- слово `угловой` заменено на `прямой`;
- отсутствует слово `модульный`.

#### Ожидаемый результат

Заголовок должен полностью совпадать со значением из формы:

`Диван угловой модульный QA Sofa 2026 раскладной`

#### Дополнительная информация

В характеристиках на той же странице владельца форма товара указана как `Угловой`, из-за чего данные внутри одной страницы противоречат друг другу.

### BR-09 — Отображаемое описание не совпадает с сохранённым

**Приоритет:** P2 — средний  
**Экраны:** Карточка товара и карточка продавца

#### Предусловия

В форме редактирования сохранено описание:

`Тестовое объявление для проверки отображения карточки и характеристик. Угловой раскладной диван`

#### Шаги воспроизведения

1. Сохранить указанное описание.
2. Открыть публичную страницу объявления.
3. Проверить блок «Описание».
4. Открыть страницу объявления владельца.
5. Проверить описание на ней.

#### Фактический результат

К сохранённому тексту добавлена отсутствующая в форме фраза:

`с ящиком для белья, подлокотниками и подушками.`

Полный отображаемый текст:

`Тестовое объявление для проверки отображения карточки и характеристик. Угловой раскладной диван с ящиком для белья, подлокотниками и подушками.`

#### Ожидаемый результат

Описание должно отображаться без самопроизвольных дополнений и полностью совпадать с текстом, сохранённым пользователем:

`Тестовое объявление для проверки отображения карточки и характеристик. Угловой раскладной диван`
